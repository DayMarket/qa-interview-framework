# Задание для собеседования на позицию QA-инженера
Вам предоставлены: 
- Проект автоматизированного тестирования на Java (исходный код и структура)
- Доступ к Orders API:
  - [Swagger UI](https://qa-interview-service.tail60205e.ts.net/swagger/index.html)
  - [Файл описания API](https://qa-interview-service.tail60205e.ts.net/swagger/doc.json)
## Ваша задача
- Проанализируйте проект и документацию API. 
- Спроектируйте и реализуйте автоматизированные тесты для [orders](https://qa-interview-service.tail60205e.ts.net/swagger/index.html#/orders) модуля Orders API.
## Критерии оценки
- Автоматизированные сценарии релевантны.
- Тесты понятны, поддерживаемы.
